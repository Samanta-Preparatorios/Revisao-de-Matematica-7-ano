2. Sistemas de equações

Um sistema reúne duas equações que devem ser verdadeiras ao mesmo tempo. A solução é o par (x, y) que satisfaz as duas.

Substituição

Despeje uma incógnita em uma equação e substitua na outra.

Adição/eliminação

Some ou subtraia as equações para eliminar uma incógnita.

SistemaIdeia

3. Ângulos, retas e ângulos opostos pelo vértice

Quando duas retas se cruzam, os ângulos opostos pelo vértice têm a mesma medida. Ângulos adjacentes sobre uma reta somam 180°.

4. Complemento e suplemento

Complementares

Somam 90°. Logo, o complemento de α é 90° − α.

Suplementares

Somam 180°. Logo, o suplemento de α é 180° − α.

5. Triângulos e quadriláteros

Triângulo

Soma dos ângulos internos = 180°.

Quadrilátero

Soma dos ângulos internos = 360°.

6. Retas paralelas cortadas por uma transversal

Nas figuras da ficha, uma transversal corta duas retas. Dependendo da posição, os ângulos podem ser correspondentes, alternos ou colaterais internos. Em muitos exercícios, a relação usada é igualdade ou soma de 180°.

7. Polígonos: soma dos ângulos internos e polígonos regulares

Soma dos internos

S = (n − 2) · 180°, em que n é o número de lados.

Regular

Todos os lados e ângulos internos têm a mesma medida.

8. Razões

Razão compara duas grandezas por meio de uma divisão. A ordem importa: 3:2 é diferente de 2:3.

Propriedade útil: multiplicar ou dividir os dois termos pelo mesmo número mantém a mesma razão.

9. Proporções

Questão 1
Equações
Fácil

Resolva: 3x + 5 = 20.

Comentário: 3x + 5 = 20 → 3x = 15 → x = 5. A alternativa correta é B.
Questão 2
Equações
Médio

Qual é a solução de 5x − 7 = 2x + 14?

Comentário: 5x − 2x = 14 + 7 → 3x = 21 → x = 7. A correta é C.
Questão 3
Equações
Difícil

Um retângulo tem perímetro 100 cm. O lado maior mede x + 10 e o menor mede x. Qual é a medida do lado menor?

Comentário: 2x + 2(x + 10) = 100 → 4x + 20 = 100 → 4x = 80 → x = 20 cm. Portanto, A.
Questão 4
Sistemas
Fácil

Resolva o sistema: x + y = 25 e 2x + 4y = 74. Qual é o valor de y?

Comentário: multiplicando x + y = 25 por −2: −2x − 2y = −50. Somando à segunda: 2y = 24, então y = 12. Alternativa D.
Questão 5
Sistemas
Médio

No sistema 2x + y = 31 e x + y = 18, qual é o valor de x?

Comentário: subtraindo a segunda equação da primeira: x = 31 − 18 = 13. Alternativa B.
Questão 6
Sistemas
Difícil

Em uma lanchonete, foram vendidos 25 produtos entre hambúrgueres e sucos. Cada hambúrguer custa R$ 12 e cada suco custa R$ 5. A arrecadação foi de R$ 265. Quantos hambúrgueres foram vendidos?

Comentário: seja h o número de hambúrgueres e s o de sucos. Temos h + s = 25 e 12h + 5s = 265. Como s = 25 − h, então 12h + 5(25 − h) = 265 → 7h = 140 → h = 20. Alternativa B.
Questão 7
Ângulos
Fácil

Duas retas se cruzam e um dos ângulos mede 50°. Quanto mede o ângulo oposto pelo vértice?

Comentário: ângulos opostos pelo vértice são congruentes. Logo, 50°. Alternativa C.
Questão 8
Ângulos
Médio

Dois ângulos adjacentes formam uma linha reta. Eles medem 3x + 20° e 2x + 10°. Determine x.

Comentário: (3x + 20) + (2x + 10) = 180 → 5x + 30 = 180 → 5x = 150 → x = 30. Alternativa D.
Questão 9
Ângulos
Difícil

Dois ângulos adjacentes medem 3x + 15° e 5x + 5°. Qual é a medida do menor deles?

Comentário: (3x + 15) + (5x + 5) = 180 → 8x + 20 = 180 → x = 20. Os ângulos são 75° e 105°. O menor é 75°. Alternativa A.
Questão 10
Complemento / suplemento
Fácil

Qual é o complemento de 25°?

Comentário: complemento = 90° − 25° = 65°. Alternativa B.
Questão 11
Complemento / suplemento
Médio

Qual é o suplemento de 38°?

Comentário: suplemento = 180° − 38° = 142°. Alternativa D.
Questão 12
Complemento / suplemento
Difícil

Dois ângulos são complementares e medem x + 10° e x + 50°. Qual é o valor de x?

Comentário: (x + 10) + (x + 50) = 90 → 2x + 60 = 90 → x = 15. Alternativa C.
Questão 13
Triângulos / quadriláteros
Fácil

Um triângulo possui ângulos de 50°, 60° e x. Qual é x?

Comentário: 50° + 60° + x = 180° → x = 70°. Alternativa A.
Questão 14
Triângulos / quadriláteros
Médio

Um quadrilátero possui ângulos internos de 90°, 90°, 110° e x. Qual é x?

Comentário: 90 + 90 + 110 + x = 360 → x = 70°. Alternativa B.
Questão 15
Triângulos / quadriláteros
Difícil

Em um quadrilátero, os ângulos internos são x, x + 60°, 100° e 2x. Qual é o valor de x?

Comentário: x + (x+60) + 100 + 2x = 360 → 4x + 160 = 360 → 4x = 200 → x = 50°. Alternativa D.
Questão 16
Paralelas + transversal
Fácil

Duas retas paralelas são cortadas por uma transversal. Um ângulo correspondente mede 60°. Quanto mede o outro ângulo correspondente?

Comentário: em duas paralelas cortadas por uma transversal, ângulos correspondentes têm a mesma medida. Portanto, 60°. Alternativa B.
Questão 17
Paralelas + transversal
Médio

Em duas paralelas cortadas por uma transversal, dois ângulos colaterais internos medem 3x + 20° e 5x. Qual é x?

Comentário: colaterais internos são suplementares: 3x + 20 + 5x = 180 → 8x = 160 → x = 20. Alternativa A.
Questão 18
Paralelas + transversal
Difícil

Em duas retas paralelas, um par de ângulos correspondentes mede 5x + 10° e 2x + 70°. Qual é a medida desse ângulo?

Comentário: correspondentes são iguais: 5x + 10 = 2x + 70 → 3x = 60 → x = 20. O ângulo é 5·20 + 10 = 110°. Alternativa C.
Questão 19
Polígonos
Fácil

Qual é a soma dos ângulos internos de um pentágono?

Comentário: S = (5 − 2)·180° = 3·180° = 540°. Alternativa D.
Questão 20
Polígonos
Médio

Qual é a medida de cada ângulo interno de um hexágono regular?

Comentário: soma = (6−2)·180° = 720°. Como é regular, 720°/6 = 120°. Alternativa A.
Questão 21
Polígonos
Difícil

Em um decágono regular, qual é a medida de cada ângulo externo?

Comentário: em um polígono regular, cada externo = 360°/n. Logo, 360°/10 = 36°. Alternativa C.
Questão 22
Razões
Fácil

Em uma turma, a razão entre meninos e meninas é 3:2. Se há 21 meninos, quantos estudantes há ao todo?

Comentário: 21 corresponde a 3 partes, então cada parte vale 7. Meninas = 2·7 = 14. Total = 21 + 14 = 35. Alternativa D.
Questão 23
Razões
Médio

A razão entre caminhões vermelhos e azuis em uma loja é 3:5. Se há 18 caminhões vermelhos, quantos são azuis?

Comentário: 18/3 = 6. Portanto, os azuis são 5·6 = 30. Alternativa B.
Questão 24
Razões
Difícil

Em um abrigo, a quantidade de cachorros é o dobro da quantidade de gatos. Ao todo há 21 animais. Quantos são gatos?

Comentário: gatos = g e cachorros = 2g. Então g + 2g = 21 → 3g = 21 → g = 7. Alternativa A.
Questão 25
Proporções
Fácil

Na proporção 8/2 = x/6, qual é o valor de x?

Comentário: 8/2 = x/6 → 8·6 = 2x → 48 = 2x → x = 24. Alternativa C.
Questão 26
Proporções
Médio

Na proporção 3/5 = x/20, qual é x?

Comentário: 3/5 = x/20 → 5x = 60 → x = 12. Alternativa B.
Questão 27
Proporções
Difícil

Qual valor de x faz 8, 2x, 12 e x + 4 formarem, nessa ordem, uma proporção?

Comentário: 8/(2x) = 12/(x+4). Fazendo o produto cruzado: 8(x+4) = 24x → 8x + 32 = 24x → 32 = 16x → x = 2. Alternativa A.
